# Security policy

This project holds user funds in escrow. Please report vulnerabilities privately.

- Use GitHub's "Report a vulnerability" (Security tab of this repository).
- Do not open a public issue for anything that could put funds at risk.
- Please include the contract, function, a short description and, if you can, a test.

Status: the contracts have had internal automated and adversarial reviews only. They have
not had an independent professional audit. See `docs/security.md` for what was reviewed and
the known limitations. Do not put funds you cannot afford to lose into these contracts.
